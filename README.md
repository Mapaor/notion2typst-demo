## About this website
This is a NextJS app that, given a Notion token (defined in an environment variable), allows converting any Notion page to Typst. The website serves as an example of [`notion2typst`](https://github.com/Mapaor/nast/packages/notion2typst).

In this case, the workspace corresponds to the Physics UB wikiblog ([fisicaubwiki.notion.site](https://fisicaubwiki.notion.site)).
