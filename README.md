## Web com a exemple
Això és una app NextJS que donat un Notion token (definit en una variable d'entorn) permet convertir una pàgina de Notion qualsevol a Typst. La web serveix com a exemple de [`notion2typst`](https://github.com/Mapaor/nast/packages/notion2typst).

En aquest cas el workspace es correspon al wikiblog de Física UB ([fisicaubwiki.notion.site](https://fisicaubwiki.notion.site)).
